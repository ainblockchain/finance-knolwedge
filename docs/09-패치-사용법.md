# 패치 내려받아 적용하는 방법

학습된 지식 패치(행 편집분)는 용량이 커서(개당 약 300 MB, 전체 4.8 GB) 저장소에
포함하지 않고 aindrive로 공유한다.

## 공유 위치

**https://aindrive.ainetwork.ai/d/VObK2uop7hs9**

최종 패치만 공유한다(중간 에포크 패치는 제외).

| 파일 | 크기 | 내용 |
|---|---|---|
| `rows-bidir-final.npz` | 477 MB | 양방향 최종 패치 (정방향 회사→코드, 역방향 코드→회사) |

정방향(회사명→코드)과 역방향(코드→회사명)을 모두 학습한 패치다. 학습 경로 기준 정방향 99.2%, 역방향 96.1%.

## 패치 구조

각 `.npz`는 세 배열을 담는다.

- `addrs` : 편집된 행의 주소 (int64)
- `before` : 편집 전 행 값 (원본 복원용)
- `after` : 학습된 행 값

## 적용

대상 모델은 반드시 동일한 Qwen3.8-Flash-Next 체크포인트(동일 토크나이저·해시 상수)여야
한다. 서빙 중 무중단으로 적용·회수한다.

```bash
# 적용
python3 scripts/patch.py apply  results/train-all/rows-bidir-final.npz
# 현재 상태 확인
python3 scripts/patch.py status results/train-all/rows-bidir-final.npz
# 회수(원본 복원)
python3 scripts/patch.py remove results/train-all/rows-bidir-final.npz
```

적용에는 서빙 엔진이 패치 훅과 함께 기동되어 있어야 한다(`ENGRAM_HOOK=1 ./serve.sh`).
자세한 훅 동작은 [04-live-patch-hook.md](04-live-patch-hook.md)를 참고한다.
