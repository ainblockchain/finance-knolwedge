# 재현부터 공유까지 — 학생용 전체 절차

이 저장소를 받아 직접 지식을 학습시키고, 자신만의 패치를 만들어, aindrive로 남에게
공유하기까지의 한 바퀴를 정리한다. 처음 하는 사람 기준으로 순서대로 따라가면 된다.

## 0. 준비물
- Qwen3.8-Flash-Next W4A16 체크포인트(약 168 GB)와 A100 40 GB급 GPU 여러 장.
- Docker, Node.js 20 이상(aindrive용), Python 3.
- 먼저 [README.md](../README.md)의 "재현 가이드"와 [06](06-how-51b-stores-knowledge.md)을
  읽어 원리를 이해한다.

## 1. 저장소 받기와 환경 설정
```bash
git clone <이 저장소 URL>
cd finance-knowledge-training-demo
cp .env.example .env        # SUDO_PW 값을 채운다
pip install numpy safetensors tokenizers
```

## 2. 서빙 엔진 기동 (검증·데모용)
```bash
ENGRAM_HOOK=1 ./serve.sh    # vLLM + PLE 오프로드 + 패치 훅 (포트 8000)
```

## 3. 학습 컨테이너 준비 (학습용)
서빙 엔진은 역전파를 지원하지 않으므로 학습은 별도 컨테이너에서 한다.
```bash
train/container.sh up       # transformers + fla 설치된 컨테이너 (GPU 4,5,6)
```

## 4. 데이터 만들기
자신이 넣고 싶은 지식의 (질의, 정답) 쌍을 모은다. 예시는 종목코드이지만, 무엇이든
같은 구조다. `data/krx.json` 형식(회사명·종목코드 등)을 참고한다.
```bash
python scripts/fetch_krx.py           # 예시: KRX 상장사 목록
```
자기 도메인이라면 `train/train_all.py`의 `TEMPLATES`/`CHAT_TEMPLATES`를 바꾼다.
새 도메인(예: 회사→대표이사) 확장법은 README "재현 가이드 4"를 참고한다.

## 5. 학습
```bash
# 감 잡기: 단일 사실 (약 30분)
train/container.sh run python3 /work/train/train_fact.py --name 픽셀플러스 --code 087600
# 본 학습: 전 종목
train/container.sh run python3 /work/train/train_all.py --micro 64 --epochs 12
# (선택) 채팅 형식·핀포인트·역방향은 README 재현 가이드 참고
```
에포크마다 `results/train-all/rows-*.npz` 패치가 저장된다. 이것이 "자신만의 모델"이다
(백본은 그대로, 테이블 행 편집분만 담긴 파일).

## 6. 검증
학습 경로 평가와 별개로, 반드시 서빙 엔진에서 자유 생성으로 최종 확인한다.
```bash
python scripts/verify_all_rows.py results/train-all/rows-<최종>.npz --out results/verify.json
python scripts/patch.py status results/train-all/rows-<최종>.npz
```

## 7. aindrive로 공유
패치 파일은 커서 git에 올리지 않는다. aindrive로 공유한다.

### 설치와 로그인
```bash
npm i -g aindrive
mkdir -p share/my-patch && cp results/train-all/rows-<최종>.npz share/my-patch/
cd share/my-patch
aindrive login --no-open        # 출력된 URL을 브라우저에서 열어 승인
```

### 폴더 연결(공유 시작)
```bash
aindrive --no-open --name my-patch   # 최초 1회는 포그라운드로 페어링
aindrive status                       # drive id 와 공유 URL 확인
```
출력된 `https://aindrive.ainetwork.ai/d/<id>` 가 공유 링크다. 이 폴더에 파일을 추가하면
같은 링크로 바로 반영된다.

### 관리
```bash
aindrive -d          # 백그라운드로 계속 서빙(detach)
aindrive logs        # 로그 보기
aindrive stop        # 서빙 중지
```

## 8. 공유 시 주의
- **패치만 공유하고 체크포인트는 공유하지 않는다.** 패치는 동일 Qwen3.8-Flash-Next
  체크포인트에서만 동작한다(동일 토크나이저·해시 상수).
- **비밀 정보 금지**: `.env`, `web/api_keys.txt`, `.aindrive/`(계정 토큰) 는 절대 git에
  올리지 않는다(이미 `.gitignore`에 있음). 공유 폴더에도 이런 파일을 두지 않는다.
- 받는 사람은 [09-패치-사용법.md](09-패치-사용법.md) 대로 `patch.py apply`로 적용한다.

## 한 줄 요약
`clone → serve → 학습 컨테이너 → 데이터 → train → verify → aindrive 공유`.
바뀌는 것은 4번(데이터)과 학습 템플릿뿐이고, 나머지 절차는 도메인과 무관하게 같다.
