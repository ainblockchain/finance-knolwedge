추론 추적: 사전이 같은 페이지를 펼칠 때 모델은 어떻게 두 종목을 구분하는가

이 페이지는 이름이 거의 같은 두 종목(예: 신한제14호스팩과 신한제12호스팩)을 골라, 코드를 생성하는 동안 토큰 위치마다 사전의 어느 페이지가 펼쳐지는지를 비교합니다. 사전은 직전 3토큰만 보므로 답 직전에서는 두 종목이 같은 페이지를 펼칩니다. 그런데도 답이 갈리는 이유를 실측으로 보여줍니다. 모든 수치는 학습 후 패치를 끼운 서빙 모델(vLLM)에서 잰 값입니다.

1. 위치별로 펼쳐지는 페이지 — 공유인가, 고유인가

각 위치의 행은 그 위치의 다음 토큰을 예측하는 데 쓰입니다. 16개 행 중 두 종목이 공유하는 행의 수(2-gram 8 + 3-gram 8)와 학습에 따른 변화량(변화 노름 평균)을 표시합니다.

위치토큰 A토큰 B→ 다음 (A / B)공유 행판정학습으로 바뀐 정도 AB

공유: 16/16 동일 페이지 · 부분: 2-gram만 동일 · 고유: 두 종목의 페이지 불일치

2. 결과: 자리별 정답 확률과 생성

3. 절제 실험: 어느 위치의 페이지를 지우면 답이 무너지는가

패치를 끼운 상태에서 한 위치의 행 16개를 0으로 만들고(다른 위치는 그대로) 다시 생성했습니다. 값이 크게 떨어지는 자리를 굵게 표시합니다.

4. 여기서 알 수 있는 것

최종 결과: 이 페이지의 스팩들을 포함해 전 종목 2,761개가 서빙 엔진 자유 생성에서 100% 정답이지만, 답 직전 페이지가 같아도 이름 위치의 페이지 → 백본 → 답 자리라는 경로를 통해 구분됩니다. 마지막 6종목은 이름 위치의 고유 페이지 376개만 1스텝 학습시키는 핀포인트 수정으로 해결했습니다.
