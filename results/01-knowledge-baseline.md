# 기존 지식 기준선 — KRX 종목코드

측정일 2026-08-28 · 모델 Qwen3.8-Flash-Next-W4A16 (TP=4, EP, greedy)
원자료 `data/krx_eval.json` · 재현 `scripts/eval_krx.py && scripts/analyze_krx.py`

## 왜 재는가

편집 대상은 모델이 **모르는** 사실이어야 한다.  아는 사실을 편집하면 "편집이
먹혔다" 와 "원래 알았다" 를 구분할 수 없다.  실제로 최초 목표였던
`삼성전자 종목코드는 005930` 은 모델이 이미 정확히 답한다.

## 방법

KRX 상장법인 2,804개 전체 + **가짜 회사 250개**(대조군).
프롬프트 `{회사명} 종목코드는`, greedy, 생성 10토큰, 첫 6자리 코드 추출.
가짜 회사는 실제 회사명 형태소를 조합해 만들었다.

## 전체

| | |
|---|---|
| 실제 상장사 정확도 | **15.98%** (448 / 2,804) |
| 코드를 아예 출력하지 않음 | 4.56% (128) |
| 코드 출력분만의 정확도 | 16.74% |
| **가짜 회사에 코드를 지어냄** | **98.40%** (246 / 250) |

가짜 회사 250개 중 246개에 그럴듯한 6자리 코드를 만들어 붙였다.
거절은 4건뿐이다.  이 모델은 종목코드 질문에 **거의 언제나 답을 만든다.**

## 시장별

| 시장 | n | 정확도 |
|---|---|---|
| 유가 (KOSPI) | 848 | **30.78%** |
| 코스닥 | 1,842 | 10.15% |
| 코넥스 | 114 | **0.00%** |

## 상장 시기별 — 지식 절벽

| 상장 시기 | n | 정확도 |
|---|---|---|
| ~2001 | 785 | 27.01% |
| 2002–2011 | 637 | 19.15% |
| 2012–2021 | 852 | 12.68% |
| **2022–2026** | **530** | **1.13%** |

연도별로 보면 2021년 18.35% → **2022년 2.08%** → 2023년 1.67% → 2024년 1.39%
→ 2025년 0.00% → 2026년 0.00%.  2021/2022 사이에 절벽이 있다.

이건 학습 컷오프가 아니라 **코퍼스 내 노출량**의 문제로 보는 게 맞다.
모델의 지식 컷오프는 2026년인데 2022년 상장사부터 이미 무너진다.
종목코드는 그 기업에 대한 텍스트가 충분히 쌓여야 학습되는 종류의 사실이다.

## 시장 × 시기 교차

| | 유가(KOSPI) | 코스닥 |
|---|---|---|
| ~2011 | 32.9% (n=636) | 15.9% (n=786) |
| 2012–2021 | 30.3% (n=155) | 9.9% (n=614) |
| 2022–2026 | 8.8% (n=57) | **0.2%** (n=442) |

KOSPI 는 시기가 늦어도 30% 를 유지하다 2022년 이후에만 무너진다.
코스닥 2022년 이후는 442개 중 **1개**만 맞혔다.

## 신뢰도는 쓸 만한 신호인가

생성 토큰 평균 logprob:

| 집단 | n | 평균 | 중앙값 |
|---|---|---|---|
| 정답 | 448 | −0.319 | −0.306 |
| 오답 | 2,228 | −0.498 | −0.452 |
| 가짜 회사 | 250 | −0.701 | −0.687 |

정답/오답 판별 AUC **0.853**.  방향은 맞지만 분포가 크게 겹쳐서 단독 임계값으로
쓰기는 어렵다.  실제로 존재하지 않는 회사에도 평균 −0.70 의 신뢰도로 답한다.

자신있게 틀린 사례 — 대개 **정답과 앞자리가 비슷한 코드**를 낸다:

```
conf -0.205  정답 189300  예측 179600  인텔리안테크
conf -0.213  정답 397030  예측 399980  에이프릴바이오
conf -0.214  정답 094360  예측 094280  칩스앤미디어
conf -0.220  정답 337930  예측 222040  젝시믹스
```

숫자열의 국소 통계는 배웠지만 개별 매핑은 모르는 상태다.
이 국소 통계가 어디서 오는지가 곧 Engram 의 2-gram/3-gram 행이다.

## 편집 실험에 대한 함의

- **좋은 대상**: 2022년 이후 상장 코스닥 종목(정확도 0.2%).  442개 중 441개를
  틀리므로 편집 전후 차이가 명확하다.
- **나쁜 대상**: 삼성전자 같은 대형 KOSPI 종목 — 이미 안다.
- **필요한 대조군**: 가짜 회사.  편집이 "그 문구에만" 작용하는지 보려면
  건드리지 않은 유사 문구의 출력이 비트 단위로 같은지 확인해야 한다.
