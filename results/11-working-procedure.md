# 작동하는 절차 — 생성 기준 첫 완전 성공

측정일 2026-08-29 · 재현 `python scripts/chainloop.py --name 필에너지 --code 378340`

## 결과

```
프롬프트  '종목코드 필에너지 '
편집 전   생성 ', 2차전지 장비 전문…'      자리별 3O 7X 8X 3X 4X 0O
편집 후   생성 '378340'                   자리별 3O 7O 8O 3O 4O 0O   정답

316초, 편집 2회 (자리 1, 2)
```

**teacher forcing 이 아니라 자유 생성**에서 6자리 전부 맞다.

## 절차

```
반복:
    생성해서 갈리는 자리 찾기          (GenScorer — 실제 생성 경로)
    가장 앞의 갈린 자리 하나만 편집    (목적함수 = 그 자리 margin 단독)
    다시 생성                          (앞을 고치면 뒤 문맥이 바뀐다)
수렴까지
```

자리 1·2 를 고치자 3·4 가 저절로 따라왔다.  **6자리를 다 편집할 필요가 없다** —
앞이 맞으면 모델이 나머지를 잇는다.

## 세 가지 설계 원칙

**1. 자리 단위로, 갈리는 곳만.**
전체를 한꺼번에 풀려던 것이 실패의 주원인이었다.  체인을 따라가며 첫 실패
지점만 고치면 문제가 1/3 로 줄고(6자리 → 2자리) 차원도 낮아진다.

**2. 공유 행에 특정 숫자를 새기지 않는다.**
`(3,7,8)` 행은 378 로 시작하는 모든 종목이 읽는다.  거기에 "다음은 3" 을
새기려 하면 다른 종목과 정면충돌한다 (실측: 3 고치고 10 깸).
`Alexander the Great` 에서 `(the, Great)` 행이 공유되면서도 작동하는 것과 같다 —
행은 "패턴이 이어진다" 만 알리고, **어느 것인지는 어텐션이 이름을 보고 정한다.**

**3. 측정은 생성 경로, 목적함수는 단일 자리.**

| 목적함수 | 측정 | 자리 1 결과 |
|---|---|---|
| 단일 자리 margin | teacher forcing | −4.06 → +0.50 (1회) |
| staged 전역 | 생성 경로 | 12회 시도, **무변화** |
| **단일 자리 margin** | **생성 경로** | **2회에 완결** |

staged(`일치 접두 + 첫 실패 margin`)가 실패하는 이유: 한 자리를 고치는 동안
접두 항은 상수이고, 남는 margin 항이 **0.0625 양자화**에 걸려 SPSA 에 기울기가
거의 없다.

## 마지막까지 발목을 잡은 두 결함

**프롬프트 공백.** `'종목코드 필에너지'` 에서 끝 공백을 떼면 모델이 숫자가 아니라
산문(`', 2차전지 장비 전문'`)을 낸다.  측정 두 곳이 서로 다른 프롬프트를 보는
바람에 14회를 헛돌았다.  이 프로젝트에서 토큰 경계 문제가 결과를 뒤집은 것이
세 번째다.

**채널 용량 오판.** 나는 여러 번 "자리당 1~2 nat 이 한계" 라고 단정했다.
무작위 방향으로만 재서 생긴 오류다.  실측:

| 실험 | 관측 |
|---|---|
| 행을 임의 방향으로 밀기 | 1~2 nat |
| 행을 0 으로 지우기 | **17~20 nat** |
| 실제 편집 (자리 2) | **−7.06 → +5.75 = 12.8 nat** |

`종목코드 필에너지 378` 에서 행을 지우면 `'3'` 이 −0.17 → −5.9 로 무너진다.
반면 무의미 조합(`qx zt vb`)은 0.28 만 변한다 — 테이블이 고정 패턴을 담당한다는
직접 증거이면서, 채널이 20 nat 규모로 열려 있다는 증거다.

## 남은 것
